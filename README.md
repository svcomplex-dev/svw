# svw

Cross-platform **svw binary releases**.

This GitHub repository is generated by the release pipeline. It intentionally
contains no svw or mxsv product source code; authoritative source development
and build gates run outside GitHub.

## Install

On macOS arm64 or Linux x64, install the latest release with:

```sh
curl --proto '=https' --tlsv1.2 -LsSf https://raw.githubusercontent.com/svcomplex-dev/svw/main/install.sh | sh
```

The installer detects the platform, downloads the matching archive and its
`.sha256` file from GitHub Releases, verifies the SHA-256 digest before
extracting, and installs the package under `~/.local/share/svw`. It creates the
`~/.local/bin/svw` command link and, when necessary, adds that directory to the
current shell's startup file. Open a new terminal after the first install if
the installer reports that it updated `PATH`.

To install another release tag or customize the destination:

```sh
curl --proto '=https' --tlsv1.2 -LsSf https://raw.githubusercontent.com/svcomplex-dev/svw/main/install.sh \
  | SVW_VERSION=v1.2.3 SVW_BIN_DIR="$HOME/bin" sh
```

Set `SVW_NO_MODIFY_PATH=1` to prevent changes to shell startup files. Run the
downloaded script with `--help` to see all supported options.
